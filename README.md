# 부르심에 기쁨으로 — 사역서신 사이트

서신 한 편 = `_posts` 폴더의 글 파일 하나.
본문을 `---` 로 나누면 **나눈 조각마다 카드 한 장**이 되고, 스크롤하면 카드가 한 장씩 떠오릅니다.

## 새 서신 올리기

1. **사진 올리기** — `images` 폴더 → Add file → Upload files
   (파일 이름은 영어·숫자로. 예: `2026-12-retreat1.jpg`)
2. **글 만들기** — `_posts` 폴더 → Add file → Create new file
   파일 이름: `날짜-영문이름.md` (예: `2026-12-01-winter.md`)
3. `_drafts/양식-template.md` 내용을 붙여넣고 고쳐 쓴 뒤 **Commit changes**

1~2분 뒤 사이트에 나타납니다.

## 카드 한 장 쓰는 법

```
![](사진파일.jpg)

한 단락 정도의 글.

---
```

- 사진 1장: `![](파일.jpg)` 한 줄
- 사진 2장: 두 줄을 **빈 줄 없이** 붙여 쓰기 → 나란히 배치
- 사진 없이 글만: 강조 카드로 표시
- 카드 구분: 위아래 빈 줄을 두고 `---`

## 맨 위 칸(머리말) 설명

| 항목 | 뜻 |
|---|---|
| `title` | 서신 제목 (필수) |
| `number` | 몇 호인지 (숫자) |
| `verse` | 표지 카드의 말씀 한 줄 |
| `cover` | 표지 카드 배경 사진 — 목록 화면 썸네일로도 쓰임 |
| `summary` | 목록에 보일 짧은 소개 |
| `prayer` | 기도제목 (기도 카드로 표시) |
| `sign` | 맺음말 (기본값: "주 안에서, ○○ 드림") |

안 쓰는 항목은 줄째 지우면 됩니다. `layout: letter` 줄은 꼭 남겨 두세요.
`cover`가 없으면 첫 번째 카드 사진이 목록 썸네일이 됩니다.

## 고치기 · 내리기 · 사이트 정보

- 고치기: 파일 열고 연필(✏️) / 내리기: `…` → Delete file
- 제목·소개·연락처·후원 안내: `_config.yml`
