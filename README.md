# 부르심에 기쁨으로 — 사역서신 사이트

새 서신은 **`_posts` 폴더에 글 파일 하나 올리면** 1~2분 뒤 사이트에 자동으로 게시됩니다.

## 새 서신 올리기 (GitHub 웹에서, 3단계)

1. 저장소에서 `_posts` 폴더로 들어가 **Add file → Create new file**
2. 파일 이름을 `날짜-영문이름.md` 형식으로 씁니다
   예) `2026-12-01-winter.md`  ← 날짜가 게시일이 되고, 목록은 날짜순으로 정렬됩니다
3. `_drafts/양식-template.md` 내용을 복사해 붙여넣고 고쳐 쓴 뒤 **Commit changes**

> 영문이름 부분은 주소(URL)에 쓰입니다. 한글·띄어쓰기 대신 영어 소문자와 `-`를 쓰세요.

## 양식 맨 위 칸 설명

| 항목 | 뜻 | 필수 |
|---|---|---|
| `title` | 서신 제목 | ✔ |
| `number` | 몇 호인지 (숫자만) | |
| `verse` | 제목 아래 들어갈 말씀 한 줄 | |
| `summary` | 목록에 보일 짧은 소개 | |
| `prayer` | 기도제목 목록 (`  - ` 로 시작) | |
| `cover` | 맨 위 대표 사진 경로 | |

쓰지 않는 항목은 줄째 지우면 됩니다. 단, `layout: letter` 줄은 꼭 남겨 두세요.

## 사진 넣기

`images` 폴더에 사진을 업로드(Add file → Upload files)한 뒤 본문에
`![설명](/joy-letters/images/파일이름.jpg)` 라고 씁니다.

## 고치기 · 내리기

- 고치기: `_posts`에서 파일을 열고 연필(✏️) 아이콘
- 내리기: 파일을 열고 `…` → Delete file

## 사이트 정보 바꾸기

제목·소개·연락처·후원 안내는 `_config.yml` 한 곳에서 바꿉니다.
